# Sources

Drop supporting material for the final report here, then link it from the relevant
section of [`../final_report.md`](../final_report.md).

Suggested contents:
- **Station / rig photos** — physical setup, camera mount, bin grid, kit box.
- **HMI screenshots** — operator console, fault banners, hand-in-bin halo.
- **CV pipeline diagram** — the 3-stage capture → annotate → train flowchart.
- **Model metrics** — per-version (V1/V2/V3) mAP / precision / recall, sample detections.
- **User-test data** — raw rating sheets, per-operator notes, the quantitative run log.
- **Lighting characterization** — the lux-vs-confidence workbook (`.xlsx`).
- **Exported Google Docs** — any findings written up elsewhere (export to PDF/`.docx`).

Images: `.png` / `.jpg`. Spreadsheets: `.xlsx` / `.csv`. Docs: `.pdf` / `.docx` /
`.md`.
